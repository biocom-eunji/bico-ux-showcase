이너뷰티 카드 · 행 그래프 3안

세로 나열은 유지하고 행의 그래프만 비교해요. 값은 시안용이에요(식단 +1 · 스킨케어 0 · 배변 0 · 회복 −1, 눈금은 ±2 가정 → 확인 필요).

A · 현재 회색 바 + 점수 영향

바(63% 등)와 오른쪽 「+1점」이 서로 다른 값이라 한 행에 숫자 두 개가 다른 뜻으로 있어요. 바 길이 근거는 정책에 없어요.

B · 양방향 바 추천

가운데 기준선에서 오른쪽 민트(+), 왼쪽 코랄(−), 변화 없음은 회색 점. 바와 오른쪽 숫자가 같은 값을 말해요.

C · 바 없음 숫자만

그래프 없이 이름 · 오늘 상태 · 점수 영향만. 가장 단순하지만 그래프 느낌이 사라져요.
